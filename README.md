# SehatPharm Pharmacy — 100 Websites Challenge #08

Your Health, Delivered. Multi-page pharmacy website (HTML/CSS/JS) with real photos in `images/`, a searchable medicine catalogue, prescription upload, and home delivery with WhatsApp checkout.

Part of the **100 Websites Challenge** by Abdullah Mahmood Official — one new business website every day.

## Pages

- `index.html` → Home (hero, medicine search, categories, delivery info)
- `medicines.html` → Searchable medicine catalogue with PKR prices
- `prescription.html` → Upload prescription & order
- `delivery.html` → Home delivery areas, timings & charges
- `about.html` → Our story, pharmacists, store gallery
- `contact.html` → Address, phone/WhatsApp, hours, form

## Tech

Plain HTML, CSS and JavaScript — shared `css/style.css` and `js/` scripts, no build step. Just open `index.html` or serve the folder with any static server.
